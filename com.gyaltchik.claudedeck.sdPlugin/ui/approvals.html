Answering takes a pair of Answer keys: tap a waiting session key to aim the pair at it, then press Allow or Deny. A session key never answers anything itself — a tap acknowledges and a hold clears it, whatever it is doing.

With this off the deck still shows which session is waiting, and the question is answered in the session's own window as usual.

This is the same setting an Approvals key carries, so a deck with one of those does not need this box at all.
